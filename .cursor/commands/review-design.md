# 設計レビューモード

`.cursor/skills/review-design/SKILL.md` に従う。

- 設計書は編集しない
- 標準観点に加え、認可・RLS・PII・秘密・情報漏洩を厚く見る
- 記録はレビュー 1 回につき 1 ファイル（`docs/90_workspace/reviews/findings/`）
- 報告で止める。どの指摘を直すか、レビューのあと何をするかは聞かない
- 報告のあと、設計の Skill だけを見直す。指摘の反映はここに含めない
- 修正・採否・コミットは、ユーザーが別の指示をしたときだけ
