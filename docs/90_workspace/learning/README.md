# Learning Gap

人間がコードを書いて詰まったことを残す場所。ハーネス（Rule / Skill / docs）の不備ではない。

ハーネス側は [../harness/README.md](../harness/README.md)。改善候補は Issue にもここにも置かない。

## 境界

| | ここ | `harness/candidates/` |
| --- | --- | --- |
| 問い | 次に何を練習するか | 今のハーネスなら防げたか |
| 採否 | 人間が Challenge をやるか | Adopt / Defer / Reject |

同じ事象を両方に分けて書いてよい。AI はファイル案まで。学習用の GitHub Issue は作らない。

## ファイル

`gaps/YYYYMMDD-short-description.md`

- 何が分からなかったか（事実）
- 次の Challenge（どのファイルで、何ができたら終わりか）
- 実施したら 1 行追記
