# レシピ手順の画像追加機能の削除

## 1. 背景・目的

現在、レシピの手順入力欄には「画像を追加」ボタンがありますが、選択した画像は画面上でプレビュー表示されるのみで、DBやストレージには保存されていません。
また、Supabaseの無料プランではストレージ容量が 1GB に制限されているため、現段階で各手順の画像まで保存する運用は適していません。

そのため、手順の入力欄から画像追加UIを削除し、手順は文章（テキスト）のみで登録・保存できるようにします。
なお、将来的な機能拡張を見据えてデータベースの画像パス用カラム（`image_url`）は保持し、レシピ本体のサムネイル画像機能もそのまま継続します。

## 2. 利用者の要求

| ID | 利用者 | 要求 |
| --- | --- | --- |
| R-01 | レシピを書く人 | 手順には文章だけを入力して保存したい。画像が保存されない状態をなくし、シンプルに入力できるようにしたい |
| R-02 | このアプリを開発・公開する人 | 将来の機能拡張に備えて、手順テーブルの画像パス用カラムは削除せず残しておきたい |
| R-03 | レシピを書く人 | レシピ本体のサムネイル画像は、これまでどおり登録・保存できるようにしておきたい |

## 3. 要件

| ID | 要件 | 応える要求 | 優先度 |
| --- | --- | --- | --- |
| FR-01 | レシピ作成・編集画面の手順入力欄に、「画像を追加」ボタンやプレビュー等の画像UIを表示しない | R-01 | 必須 |
| FR-02 | 手順の文章のみを入力して、レシピを正常に作成・保存できる | R-01 | 必須 |
| FR-03 | レシピ本体のサムネイル画像は、これまでどおり登録・保存できる | R-03 | 必須 |

## 4. スコープ・制約

### 含める

- レシピ作成・編集画面の手順入力欄から「画像を追加」UI（ファイル選択・プレビュー）を削除すること
- 手順の文章のみを入力・保存できることの確認

### 含めない

- レシピ本体のサムネイル画像機能の変更（現状のまま維持）
- データベース（`recipe_instructions` テーブル）の `image_url` カラムの削除・変更
- 設計書（`docs/02_design`）の新規作成

## 5. 受け入れ条件

- [ ] レシピ作成・編集画面の手順入力欄に、画像を追加するボタンやUIが存在しないこと
- [ ] 手順の文章のみを入力して、レシピが正常に保存・更新できること
- [ ] データベースの手順テーブルにある画像パスカラム（`image_url`）が残っていること
- [ ] レシピ本体のサムネイル画像が、これまでどおり登録・保存できること
