# レシピ更新

## スコープ

### 含める

- 既存レシピの本文・人数・時間・下書き／公開・材料・手順・カテゴリ・サムネイルの更新
- 作者本人だけが更新できる
- 詳細画面から `/recipe/[id]/edit` へ進む導線
- Server Action + 編集画面

### 含めない（別ブランチ / 別 PR）

- レシピ削除
- 家族メンバーによる編集（子テーブルの INSERT は作者のみ）
- 手順画像の Storage 保存
- HEIF 対応

## 完了条件

- [ ] 作者が詳細から編集画面を開ける
- [ ] 作者以外には編集ボタンが出ない
- [ ] 編集内容を保存すると詳細に反映される
- [ ] サムネイルの差し替え・削除ができる
- [ ] 関連 unit test が通る
