# レシピ編集

## 何ができるか

作者が、既存レシピの内容とサムネイルを直して保存する。

## ルート

| パス | 認証 | Primary Action |
| --- | --- | --- |
| `/recipe/[id]/edit` | 必要 | 変更を保存（公開済み / 下書きで文言が変わる） |

## 情報設計

- `RecipeForm` に既存レシピを渡す
- 作者以外は 404
- ボタン: 公開済みは「変更を保存」「下書きに戻す」。下書きは「公開して保存」「下書きのまま保存」

## 導線

| 入る | 出る |
| --- | --- |
| 詳細の編集 | 保存後は詳細 |

## 含まない

- 家族メンバーの編集
- 削除
