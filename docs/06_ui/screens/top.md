# ホーム（レシピ一覧）

## 何ができるか

見られるレシピを一覧し、登録や検索、お気に入り切替へ進む。ログイン後の拠点。

## ルート

| パス | 認証 | Primary Action |
| --- | --- | --- |
| `/top` | 必要 | レシピを追加（ヒーロー）。一覧の主目的は眺めて開くこと |

お気に入りはカード上の補助。検索はクイックアクセス。

## 情報設計

- ファーストビュー: ヒーローと一覧
- 空状態: 説明と登録への CTA
- 未実装カード（献立・買い物）は「実装予定」で押せない

## 導線

| 入る | 出る |
| --- | --- |
| ログイン成功、ナビ、ロゴ | 詳細、作成、検索、家族、ログアウト |

## 含まない

- `/top-preview/*`
