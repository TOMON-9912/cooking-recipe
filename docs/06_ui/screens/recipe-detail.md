# レシピ詳細

## 何ができるか

1 件のレシピを読み、作者なら編集へ進む。

## ルート

| パス | 認証 | Primary Action |
| --- | --- | --- |
| `/recipe/[id]` | 必要 | 作者: 編集する。作者以外: 読む（Primary を増やさない） |

## 情報設計

- ファーストビュー: 料理名と写真
- 見えない ID は 404
- 作者以外に編集ボタンを出さない

## 導線

| 入る | 出る |
| --- | --- |
| 一覧・検索のカード | 作者 → `/recipe/[id]/edit` |

## 含まない

- 削除 UI
