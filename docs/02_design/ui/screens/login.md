# ログイン

## 何ができるか

メールとパスワードで入る。ゲストで試す導線もあるが、ゲストの仕様は [guest-login.md](./guest-login.md)。

## ルート

| パス | 認証 | Primary Action |
| --- | --- | --- |
| `/login` | 不要 | ログインする |

## 情報設計

- ファーストビュー: メール・パスワードとログインボタン
- 空状態: なし（フォーム）
- 失敗時: フォーム上のエラー

## 導線

| 入る | 出る |
| --- | --- |
| LP、ヘッダー、保護ルートからの redirect | 成功 → `/top`（`redirectTo` は未使用） |

## 含まない

- サインアップフォーム本体
- ゲスト実装の詳細
