# ランディング（`/`）

## 何ができるか

未ログインの人に、家族の味を残すアプリだと伝え、登録またはログインへ進める。

## ルート

| パス | 認証 | Primary Action |
| --- | --- | --- |
| `/` | 不要 | はじめる（サインアップ） |

ログイン・ゲストは Secondary。

## 情報設計

- ファーストビュー: コンセプトと主 CTA
- 空状態: なし

## 導線

| 入る | 出る |
| --- | --- |
| 直接、未ログイン時のロゴ | `/signup`、`/login`、ゲスト |

## 含まない

- `/lp/*` の検証用バリエーション（本番導線外）
