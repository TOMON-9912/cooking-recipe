# 家族に参加（承認）

## 何ができるか

自分宛ての招待について、家族名を確かめて「この家族に参加する」を押せる。使えない招待のときは、次の行動（オーナーに再発行を頼む）が分かる。

## ルート

| パス | 認証 | Primary Action（画面内 1 つ） |
| --- | --- | --- |
| `/family/join` | 必要 | この家族に参加する |

実装の page は未作成。既存の `src/app/family/` には `/family` と `/family/new` だけがある。このパスは新規。

## 情報設計

- ファーストビュー: 家族名と、参加するボタン。オーナー名、メンバー、レシピは出さない
- 未ログイン: ログインが必要と分かる。ログイン後にこの画面へ自動では戻らない。本人が家族管理（`/family`）から進む（FR-13）
- ゲスト: 参加できない理由と、本登録への案内（ボタンは出さない）
- 既に家族に所属: 「すでに家族に入っています」と、`/family` へのリンク（Secondary）
- 人数がいっぱい: 上限に達していることと、オーナーへ頼む案内
- 自分宛ての招待が期限切れ・取り消し済み・承認済み: その理由と、オーナーへの再発行の依頼
- 招待が無い・他人宛て: 理由は区別せず「この招待は使えません」と、オーナーへの再発行の依頼。`/family` へのリンク
- 失敗時: 承認に失敗したら画面内で理由を出す。招待は消費されない

自分宛てが複数あるときは、家族名の一覧から 1 件を選んで承認する。Primary は選んだ 1 件の「参加する」だけ。

## 導線

| 入る | 出る |
| --- | --- |
| `/family` の自分宛ての招待から | 成功 → `/family`（メンバーとして確認できる）。失敗・拒否 → 同じ画面内で案内 |

## 含まない

- 招待の発行（オーナー用。[family.md](./family.md)）
- 家族の切り替え、脱退
- 秘密のトークン付き URL
- ログイン後の自動戻り
